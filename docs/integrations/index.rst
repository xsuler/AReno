Integration
===========

AReno integrates with external libraries, frameworks and tools. This section
explains what each integration provides, how to set it up and how to use it
with AReno.

Each guide covers the external dependency's requirements, configuration,
supported interfaces and usage examples. Follow the guide for the dependency
you want to connect.
